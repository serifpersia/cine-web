# Cine-Web

Cine-Web is a simple, self-hosted web application for streaming TV shows and movies locally.

## Installation

### Requirements

- Node.js (latest LTS version recommended)
- npm (included with Node.js)

### Setup

1. Download the latest Cine-Web release ZIP.
2. Extract the ZIP archive to a folder of your choice.
3. Open a terminal and navigate to the extracted directory:

   ```bash
   cd path/to/cine-web
