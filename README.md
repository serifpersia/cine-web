# Cine-Web

Cine-Web is a simple, self-hosted web application for streaming TV shows and movies locally.

## Features

- Stream TV shows and movies from your local library
- Simple and lightweight web interface
- Easy setup and installation
- Runs entirely on your own machine

## Requirements

Before installing Cine-Web, make sure you have:

- Node.js (LTS version recommended)
- npm (included with Node.js)

## Installation

1. Download the latest Cine-Web release ZIP.
2. Extract the ZIP archive.
3. Open a terminal and navigate to the extracted directory:

   ```bash
   cd path/to/cine-web
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the application:

   ```bash
   npm start
   ```

6. Open your browser and visit:

   ```
   http://localhost:3000
   ```

## Usage

After starting the application, open `http://localhost:3000` in your browser. From there, you can browse and watch your TV shows and movies through the Cine-Web interface.

## Troubleshooting

### Node.js is not installed

Download and install Node.js from the official website:

https://nodejs.org

### Port 3000 is already in use

Close the application using port `3000` or configure Cine-Web to use a different port.
